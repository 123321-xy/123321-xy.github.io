# xinyi hu — home page

Live at **https://123321-xy.github.io**

A single hand-written `index.html` (no build step) served by GitHub Pages. Things to poke:

- a live proxy diagram in the hero — toggle "require TLS" and click to send traffic
- a fake `psql` shell you can query (`help` to start)
- a quorum playground and a config-rollback toy in the projects section
- a status page, and a konami code easter egg

To preview locally:

```bash
python3 -m http.server 4173
```
